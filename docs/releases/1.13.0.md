# dsh-purge-community 1.13.0

本版是一次减法发布：去掉插件内置的检查更新能力，并清空仓库里的测试与草稿产物。

## 移除

- 更新子系统：`update.js`、`update-policy.js`、`update-state.js`、`update-install.js`、`update-integrity.js`、`update-net.js`、`update-targets.js`、`update-http.js`、`update-download.js`、`update-mirror.js`、`update-socks.js`、`update-system-proxy.js`。
- HTTP 接口：`GET/POST /dsh-purge/update`；`/dsh-purge/community` 的 `check`、`update`、`preferences` 操作。
- 面板：状态页「版本管理」与检测/更新按钮、维护页「自动检查更新」「自动安装更新」「更新通道（代理 / GitHub 密钥）」、RedTeam 控制台右上角版本徽标。
- 配置：`autoUpdateOnStart` 与 `$DSH_HOME/dsh-purge/update-preferences.json`、`update-status.json` 不再读写。
- 文档：`docs/AUTO-UPDATE.md`、`docs/maintenance-update-state.md`、`docs/update-channel-122.md`、`docs/update-layout-130-132-137.md`。

## 保留

- 维护页的本机备份、回滚、备份清理与最近动作。
- 归档校验：`Maintenance.install()` 仍按 tar 清单校验归档结构；独立安装器（`scripts/bootstrap-install.mjs`）继续做来源、SHA256 与预算校验。
- 凭据文件权限保护：`lib/secret-file.js`（原 `update-secrets.js`），红队凭据库继续复用。

## 清理

删除 `test/`、`packages/purge-panel/test/`、`prompt-lab/`、`docs/validation/`、`dist/`、`.scratch/` 及仓库根目录的 `*.tgz`；`package.json` 只保留构建、检查与打包脚本，CI 只跑构建一致性与打包冒烟。

## 升级方式

用官方 CLI 显式安装本版发行包：

```sh
dsh plugin --profile web add "https://github.com/kingcharleslzy-ai/dsh-purge/releases/download/v1.13.0/dsh-purge-community-1.13.0.tgz"
```

安装前自动备份，回滚在「Purge → 状态 → 维护 → 本机备份」中完成。
