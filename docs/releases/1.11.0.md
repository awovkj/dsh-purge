# dsh-purge-community 1.11.0

源码完成日期：2026-11-15。输入分析日期：2026-11-14。当前是本地源码和生成物升级，发行 TGZ 尚未打包或发布。

本版为三模式补充发现和工作反馈能力。`evidence.diff` 对比当前完整响应，`surface.from_sourcemap` 离线分析已采集 map；`http.capture_batch` 顺序运行明确的只读请求，复用当前范围、身份、Cookie、SRC 停止和原生幂等。错误、取消或不完整响应保留已经完成的 E-ID 和实际恢复信息，未知结果停止，不自动重放。

`workspace.list/read` 只提供当前靶标固定目录的非私密材料，先完整脱敏再分页；`intel.import/search/get` 从本地 NVD/KEV/GHSA JSON 构建有界缓存和版本候选。来源声明、KEV 标签、CVSS、文件摘要或匹配版本均不授予漏洞确认、严重级或覆盖。缓存和输入异常保留原字节，复杂 CPE/范围保持 unknown。

技能元数据有实际目录消费者，新增八篇原创专题与 CWE 导航。模式不提供、尚未实现能力或元数据错误显示 blocked；公开索引未核实运行时和实际工具注册，所需前提保留 unknown。`workflow.advice` 使用当前精确证明及 SRC 停止给出离线建议；typed 失败归因区分平台管控、目标状态、运行错误和未知派发，目标 403 不推断为 WAF。角色、技能与模式指引继续由共享源码生成。

修复独立 `stop_offset` 和委派失败名额处理。已派发但没有可信 no-start/终态回执的任务保留占位；真实完成回收，未运行 reservation 继续按既有规则处理。

Pojun 仅提供设计参考，新增代码和专题独立编写，不搬入 AGPL 代码或技能全文。本项目 MIT 许可证和随包 awa-ddd 2.2.0 来源清单保留，独立 Pojun、AWA、用户配置和正在运行的 DSH 没有被部署或改写。
