# dsh-purge-community 1.12.0

持续源码升级日期：2026-11-15至16。发行TGZ尚未打包或发布。

本版修正SQL/模板当前证明、模型review权限和SRC新停止准入；冻结campaign成员与本活动覆盖，保留共享尝试/冷却/未知效果。N/A适用性草稿不能缩分母或授予结项。实际基线、独立控制、精确输入/身份、完整artifact、机器claim及严重级上限共用核验。

新增需求驱动 `tool.route`，接入模式、顶层工具描述、技能和workflow。已有JS/map优先离线，HTML/DOM需求准备Playwright，公开GET复放使用Yak当前TLS/fuzzer/no-follow契约，已有scanner结果复用TscanPlus本靶标namespace。认证备用路径保留身份，WSL由操作者固定，模型不能填写ready/backend。

原请求路由保留唯一实际身份与URL，不默认换成管理员会话；歧义、额外业务头、匿名Cookie及公开脱敏URL明确要求准备。Yak只构造公开无正文GET，不是完整原包重放；通用私有请求句柄执行入口仍未实现。普通v1 analyst复核稿不自动触发SRC停止，显式停止也须可信证明。

明确只读batch使用单个固定worker并逐派发重验范围、身份、Cookie和live SRC停止；匿名Cookie链保留逐项门面。真实发送/接收、捕获正文bytes和耗时分别计量，精确复用为0新请求，不明为null。增加有限JS跨模块引用图、CVE/GHSA去重与版本冲突保留。

有界GET访问边界和managed反射HTML XSS配方已实现；未实现provider、缺件、模式禁止与未完成项继续显示。安全机制真值/浏览器适配测试主要使用模拟；实际localhost批量、固定WSL worker/AST/HTTP/sqlmap版本probe及TscanPlus三个只读profile有独立真实回执。

新增15场景工具选择评分器与反例测试。它检查可观察trace的选择和准确参数，不认证模型或工具执行；真实模型选择率、tokens与总体漏洞准确率仍未测。真实Playwright/Yak、完整宿主/GUI/委派调度与授权预生产目标未验收。

组件适配版本、85项来源清单、README/NOTICE、模式及客户端生成物同步，保留awa-ddd2.2.0 MIT来源与上游SHA256。没有下载/安装工具、访问第三方目标、发布/安装本插件、apply、退出或重启正式DSH，没有提交或新分支。
